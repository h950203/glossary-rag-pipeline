# 대표어와 확장 표현 검토 요청

첨부한 JSONL의 한영 원문과 관측 정렬쌍을 읽고, 대표어와 확장 연결이 문맥의 뜻을 보존하는지 검토해줘.

- `line_id`와 `pair_index`로 사례를 특정해줘. 한영 정렬 자체가 어긋난 경우에는 그룹화 문제와 구분해줘.
- `representative`는 표현군의 기준어다. `expansion`의 수식어가 개념을 특정하면 전체 표현을 독립 후보로 남길지 판단해줘.
- `representative_observed_in_sentence=false`는 그 대표어가 별도 정렬 단위로 관측되지 않았다는 표시다. 원문에서 실제 관측된 확장 표현을 확인해줘.
- `unassigned`에서는 별도 등재할 복합어와 일반적인 표현을 구분해줘.
- 한국어와 영어의 소속을 각각 검토해줘. 양쪽 대표어의 번역 대응이 확실한지도 따로 판단해줘.

결과를 문장 ID, 정렬쌍 번호, 언어, 실제 표현, 기존 대표어, 권장 대표어 또는 별도 등재, 이유로 정리해줘. 검토 범위도 적어줘.
