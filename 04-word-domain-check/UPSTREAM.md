# Gemma 도메인 검수

- **가져온 버전** — `PP/word-domain-check_v1.9.4.1`, `child_review` 방식.
- **통합 변경** — 실행기가 `PP_STAGE_RESULT_ROOT`를 받아 중간 로그를 중앙 실행 폴더에 저장한다. 통합 실행기는 개별 오류를 기록하고 검증된 목표 용어로 계속하도록 기본 옵션 `--allow-record-errors`를 전달한다. 분류 프롬프트와 분류표는 복사한 원본을 사용한다.
- **입출력** — 한영 용어와 예문으로 의미·전문성·소속을 검토한다. 목표 분야 채택 파일을 용어집 변환으로 전달한다. 같은 대분류, 다른 분야 및 전체 판정을 함께 공개한다.
- **업데이트** — `target_domain.jsonl`에 `status`, `terms.ko/en`, `original.sample_sentences`가 유지되는지 확인한다. 유효한 목표 용어와 개별 오류가 섞인 실행의 종료 코드, 목표 용어가 없는 실행의 중단, 오류 파일과 사람이 검수한 `--gold-file` 명세도 확인한다.
